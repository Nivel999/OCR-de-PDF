# templates/

Reusable boilerplate the AI can copy when generating repetitive artifacts for this
project — e.g. a new feature folder skeleton, a PR description template, a migration
file header, a test scaffold, or a component boilerplate.

Add one file per template. Reference them from `coding_conventions.md` or task specs
so the assistant knows when to use each. Delete this folder if the project has no
reusable templates.
